About

Enterprise systems, shipped end to end

I'm a Senior Software Developer based in Islamabad, with 4 years of full-stack experience. I currently work at GeekPie, building enterprise .NET applications and client systems — including analytics and backend platforms for Kahramaa, a national utility organization in Qatar.

My work tends to sit across the whole stack: designing the data model, building the ASP.NET Core API on top of it, wiring up the Angular or React front end, and taking the result through Azure DevOps pipelines to a deployed IIS environment. I've also spent real time in the less glamorous parts of the job — production incident response, database migrations between environments, and reworking access architecture under an Entra ID model.

Before GeekPie, I worked at Bingeable Technologies and VisionTech 360, where I built systems including a live, Airbnb-style booking platform and an OSINT intelligence platform.
